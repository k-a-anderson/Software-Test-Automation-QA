# Software-Test-Automation-QA
# How can I ensure that my code, program, or software is functional and secure?
To ensure that my code, programs, and software are functional and secure, I make sure to focus on thorough unit testing, input validation, and error handling. During Project One, I wrote JUnit5 tests for each service Contact, Task, and Appointment, to catch invalid inputs such as null values, incorrect lengths, or improperly formatted data. By designing tests that covered both valid and invalid inputs, I was able to confirm that the services worked correctly under a variety of different conditions. I also applied defensive programming by validating all inputs inside constructors and setter methods to prevent security vulnerabilities and unexpected behavior.
# How do I interpret user needs and incorporate them into a program?
I interpret user needs by carefully reading and translating requirements into clear code behaviors. In Project One, I broke down the client’s specifications into specific coding rules (e.g., a contact’s phone number must be exactly 10 digits, names must not exceed 10 characters). Each requirement became either a validation inside the class or a condition checked in the corresponding JUnit tests. I ensured that my code strictly followed these rules so that the final product matched the client's expectations.
# How do I approach designing software?
I approach designing software by starting with a focus on simplicity, modularity, and testability. I break down the program into smaller objects (Contact, Task, Appointment) and services (ContactService, TaskService, AppointmentService) that each handle a single responsibility. I design classes so that their functions are easy to test and extend later. Writing the unit tests early on also helped me shape the design by highlighting where inputs needed stricter validation or where edge cases needed extra attention. My design approach ensures that my software is easy to maintain, scalable, and meets the user requirements without unnecessary complexity.
